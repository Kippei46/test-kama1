# スライド要件との対応

## スライド13〜16
オンライン機能とオフライン機能の一覧に合わせ、現在地・避難ルート、多言語、初期行動、交通情報、通行不可報告、道路混雑、通知、避難所管理の画面を追加。

## スライド23
画面遷移図を参考に、地図を中心としてメニューから交通情報、報告、初期行動、通知、オフライン、管理者画面へ遷移できる構成。

## スライド24〜25
由比ヶ浜津波デモボタンで、由比ヶ浜位置・津波ハザード・交通運休・道路混雑をまとめて再現。

## スライド29〜33
公的ハザードを優先し、ユーザー報告と道路混雑は補助情報としてルート評価へ加点。避難所は管理者の開設ON/OFFを候補表示へ反映。

## スライド36〜38
PWA、Service Worker、Geolocation API、Leaflet、OpenStreetMapの構成を維持。

## スライド40・47
フロントエンド、端末内保存、オンラインルーティング、本番バックエンド想定、将来のGraphHopper構成をシステム構成画面に整理。

## 未実装扱い
気象庁XML、ODPT本接続、Flask/MySQL本番運用、GraphHopper完全オフライン探索は、画面上でもデモ・設計段階として区別。
